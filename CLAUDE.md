# AirBridge

macOS 14+ menu bar app (SwiftUI, Apple Silicon) that runs AirConnect's `airupnp`
so Sonos/UPnP speakers appear as AirPlay targets. See README.md for build,
signing and notarising.

- `AirBridge.xcodeproj` is generated by XcodeGen from `project.yml` and committed.
  Edit `project.yml`, then `xcodegen generate`; CI commits a regenerated project on
  branches and fails on `main` if it's stale.
- Testable logic lives in `Packages/AirBridgeCore` (LogParser, SpeakerRegistry,
  DeviceConfig, LaunchArguments, Backoff). Keep AppKit/SwiftUI out of it.
- airupnp flags: verify against `airupnp -h` for the bundled version, never assume.
  `-z` does not exist on macOS (use `-Z`).
- The bundled binary is `Vendor/AirConnect/airupnp-macos-arm64-static` (the plain
  build aborts on macOS). Record any update in `Vendor/AirConnect/VERSION.md`.
- It must live in `Contents/Helpers` and be signed with the hardened runtime by
  `scripts/embed-airupnp.sh`. No App Sandbox, no entitlements.
- The app makes no network calls of its own.
- No compiler in the cloud container: CI (`.github/workflows/build.yml`, macos-15)
  is where it builds and tests.
